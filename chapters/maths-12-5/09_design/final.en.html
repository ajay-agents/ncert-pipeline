Example: f(x)=x

Prove that the identity function on real numbers given by f(x) = x is continuous at every real number.

Given
The function is clearly defined at every point, and f(c) = c for every real number c.
Also,
lim x → c f(x) = lim x → c x = c
Thus, lim x → c f(x) = c = f(c), so the function is continuous at every real number.
We have now defined continuity at a single point.
Next, we extend this to continuity of a function as a whole.
Definition 2 A real function f is said to be continuous if it is continuous at every point in the domain of f.
Conclusion
This needs a little more explanation.
Suppose f is a function defined on a closed interval [a, b].
For f to be continuous, it must be continuous at every point in [a, b], including the end points a and b.
Continuity of f at a means
lim x → a+ f(x) = f(a)
and continuity of f at b means
lim x → b- f(x) = f(b)
Note that lim x → a- f(x) and lim x → b+ f(x) do not make sense here.
It follows that if f is defined at only one point, it is continuous there — i.
e.
, if the domain of f is a single point, f is a continuous function.
