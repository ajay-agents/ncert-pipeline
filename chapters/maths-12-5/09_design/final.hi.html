Continuity of a linear function at a point

x = 1 पर फलन f(x) = 2 x+3 के सांतत्य की जाँच कीजिए।

निष्कर्ष
पहले यह ध्यान दीजिए कि फलन, x = 1 पर परिभाषित है और इसका मान 5 है।
अब फलन की x = 1 पर सीमा ज्ञात करते हैं।
स्पष्ट है कि
lim x → 1 f(x) = lim x → 1(2 x+3) = 2(1)+3 = 5 है।
अत:
lim x → 1 f(x) = 5 = f(1)
अतएव x = 1 पर f संतत है।

f(x) = x3+3, यदि x ≠ 01, यदि x = 0

Continuity of a constant function

उन बिंदुओं की जाँच कीजिए जिन पर अचर फलन (Constant function) f(x) = k संतत है।

निष्कर्ष
यह फलन सभी वास्तविक संख्याओं के लिए परिभाषित है और किसी भी वास्तविक संख्या के लिए इसका मान k है।
मान लीजिए कि c एक वास्तविक संख्या है, तो
lim x → c f(x) = lim x → c k = k
चूँकि किसी वास्तविक संख्या c के लिए f(c) = k = lim x → c f(x) है इसलिए फलन f प्रत्येक वास्तविक संख्या के लिए संतत है।

Continuity of the identity function

सिद्ध कीजिए कि वास्तविक संख्याओं के लिए तत्समक फलन (Identity function) f(x) = x, प्रत्येक वास्तविक संख्या के लिए संतत है।

निष्कर्ष
स्पष्टतया यह फलन प्रत्येक बिंदु पर परिभाषित है और प्रत्येक वास्तविक संख्या c के लिए f(c) = c है।
साथ ही
lim x → c f(x) = lim x → c x = c
इस प्रकार, lim x → c f(x) = c = f(c) और इसलिए यह फलन f के प्रांत के सभी बिंदुओं पर संतत है ।

Discontinuity of a piecewise linear function at x=1

निम्नलिखित फलन के सांतत्य पर विचार कीजिए:

f(x) = {x+2, यदि x ≤ 1x-2, यदि x>1

जानकारी
फलन f वास्तविक रेखा के प्रत्येक बिंदु पर परिभाषित है।
मान रखो
दशा 1 यदि c<1, तो f(c) = c+2 है।
इस प्रकार lim x → c f(x) = lim x → c x+2 = c+2 है।
अतः 1 से कम सभी वास्तविक संख्याओं पर f संतत है।
दशा 2 यदि c>1, तो f(c) = c-2 है।
इसलिए lim x → c f(x) = lim x → c(x-2) = c-2 = f(c) है।
अतएव उन सभी बिंदुओं पर जहाँ x>1 है, f संतत है।
निष्कर्ष
दशा 3 यदि c = 1, तो x = 1 पर f के बाएँ पक्ष की सीमा, अर्थात्
lim x → 1- f(x) = lim x → 1-(x+2) = 1+2 = 3
x = 1 पर f के दाएँ पक्ष की सीमा, अर्थात्
lim x → 1+ f(x) = lim x → 1-(x-2) = 1-2 = -1
अब चूँकि x = 1 पर f के बाएँ तथा दाएँ पक्ष की सीमाएँ संपाती (coincident) नहीं हैं, अत: x = 1 पर f संतत नहीं है।
इस प्रकार f के असांतत्य का बिंदु केवल मात्र x = 1 है।
इस फलन का आलेख आकृति 5.4 में दर्शाया गया है।

Points of discontinuity of a three-piece function

निष्कर्ष
पूर्ववर्ती उदाहरण की तरह यहाँ भी हम देखते हैं प्रत्येक वास्तविक संख्या x ≠ 1 के लिए f संतत है।

इस प्रकार f के असांतत्य का बिंदु केवल मात्र x = 1 है।

Continuity of a function undefined at zero

सिद्ध कीजिए कि फलन f(x) = xn, x = n, पर संतत है, जहाँ n एक धन पूर्णांक है।

निष्कर्ष

x = n पर, f(n) = nn
lim x → n f(x) = lim x → n(xn) = nn
यहाँ, x = n पर, lim x → n f(x) = f(n) = nn
अतः, x = n पर, जहाँ n एक धन पूर्णांक है, फलन f संतत है।

f(x) = |x|-|x+1| द्वारा परिभाषित फलन f के सभी असांत्यता के बिंदुओं को ज्ञात कीजिए।

जानकारी
दिए गए फलन को प्रत्येक वास्तविक संख्या के लिए परिभाषित मानते हुए, फलन f को दो फलनों h और g के संयोजन में लिख सकते हैं (f = g-h)।
जहाँ, g(x) = |x| और h(x) = |x+1| है।
यदि h और g दोनों ही संतत फलन हैं, तो f भी एक संतत फलन होगा।
मान रखो
फलन g(x) = |x|
इस फलन g को पुनः व्यवस्थित करने पर,
g(x) = -x, यदि x<0x, यदि x ≥ 0
माना, k कोई वास्तविक संख्या है।
प्रश्नानुसार k<0 या k = 0 या k>0
पहली स्थिति: यदि, k<0,
g(k) = 0 तथा lim x → k g(x) = lim x → k(-x) = 0, यहाँ, lim x → k(x) = g(k)
अतः, फलन g, 0 से छोटी सभी वास्तविक संख्याओं के लिए संतत है।
दूसरी स्थिति: यदि, k = 0 पर, g(0) = 0+1 = 1
बाएँ पक्ष की सीमा  = lim x → 0- g(x) = lim x → 0-(-x) = 0
दाएँ पक्ष की सीमा  = lim x → 0+ g(x) = lim x → 0+(x) = 0,
यहाँ, x = 0 पर, फलन g के बाएँ पक्ष की सीमा = दाएँ पक्ष की सीमा  = g(0)
अतः, x = 0 पर, फलन g संतत है।
तीसरी स्थिति: यदि, k>0,
g(k) = 0 तथा lim x → k g(x) = lim x → k(x) = 0, यहाँ, lim x → k g(x) = g(k)
अतः, फलन g, x>0, के लिए संतत है।
इसप्रकार, फलन g, सभी वास्तविक संख्याओं के लिए संतत है।
निष्कर्ष
फलन h(x) = |x+1|
इस फलन h को पुनः व्यवस्थित करने पर,
h(x) = {-(x+1), यदि x<-1x+1, यदि x ≥ -1
माना, k कोई वास्तविक संख्या है।
प्रश्नानुसार k<-1 या k = -1 या k>-1
पहली स्थिति: यदि, k<-1,
h(k) = -(k+1) तथा lim x → k h(x) = lim x → k-(k+1) = -(k+1), यहाँ, lim x → k h(x) = h(k)
अतः, फलन h,-1 से छोटी सभी वास्तविक संख्याओं के लिए संतत है।
दूसरी स्थिति: यदि, k = -1 पर, h(-1) = -1+1 = 0
बाएँ पक्ष की सीमा  = lim x → -1- h(x) = lim x → -1--(-1+1) = 0
दाएँ पक्ष की सीमा  = lim x → -1+ h(x) = lim x → -1+(x+1) = -1+1 = 0,
यहाँ, x = -1 पर, फलन h के बाएँ पक्ष की सीमा = दाएँ पक्ष की सीमा = h(-1)
अतः, x = -1 पर, फलन h संतत है।
तीसरी स्थिति: यदि, k>-1,
h(k) = k+1 तथा lim x → k h(x) = lim x → k(k+1) = k+1, यहाँ, lim x → k h(x) = h(k)
अतः, फलन h, x>-1, के लिए संतत है।
इसप्रकार, फलन h, सभी वास्तविक संख्याओं के लिए संतत है।
इसप्रकार, g और h दोनों ही संतत फलन हैं, अतः f भी एक संतत फलन होगा।
